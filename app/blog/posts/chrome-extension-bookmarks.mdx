## Installation

1. **From Chrome Web Store**: Search for "Personal Bookmarks Manager"
2. **Manual Installation**:
   - Download the extension package
   - Navigate to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select the extension directory

## Usage

### Creating Bookmarks
1. Click extension icon or press `Ctrl+Shift+B`
2. Current page automatically detected
3. Choose folder and add tags
4. Click "Save"

### Organizing
- Drag bookmarks between folders
- Right-click for context menu
- Use bulk selection with Ctrl/Cmd
- Create nested folders

### Searching
- Press `/` for quick search
- Filter by tags or folders
- Search by URL or title
- Recent searches saved
